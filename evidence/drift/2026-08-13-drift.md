## Why this matters

These files are the contract every agent reads before acting.
An instruction that no longer matches the repository does not
fail loudly -- it quietly misleads the next agent, and the
resulting mistake looks like an agent error rather than a
documentation error.

## What is being asked of you

This PR reports drift; it does not guess at the wording. Decide
whether each finding means the docs should be corrected or the
repository should be. Both are legitimate outcomes.

The detector also had no guard against reporting drift it had already reported.
Because merging a drift report is itself a push to `main`, it re-detected the
same unfixed findings and opened PR #26 — a report about the merge of a report.
That would have continued indefinitely, one PR per merge.

Both bugs share a shape worth naming: **a detector that cries wolf gets ignored
exactly when it is right.** Twelve false positives buried four true ones, and an
infinite loop would have trained the reviewer to close these unread.

## Follow-up (PR #28)

The run triggered by merging #27 reported **one** finding, down from 19 — and it
was the sentence in `AGENTS.md` §0 that *defines* the path convention. The rule
flagged its own definition.

No PR opened, but for the wrong reason: PR #26 was still open at the time and
the pre-existing "a drift PR is already open" guard suppressed it. The new loop
guard was never exercised. Once #26 was closed, the next merge would have opened
a PR for that false positive.

Two fixes, both verified:

1. A line-scoped `<!-- drift-ignore-next-line -->` marker, for documentation that
   illustrates a path rather than referencing a file. Negative-tested: findings
   immediately before and after a marked line are still reported.
2. The loop guard now compares only the bullets inside `## Findings`. It
   previously matched every `- ` line in the file, so the moment a reviewer
   wrote a bulleted resolution section the previous report would stop comparing
   equal to its own findings and the loop would resume. This report survived
   only because its resolution used a table. Demonstrated in a fixture.

The illustration was also changed to a domain-neutral path. The root contract
travels with the template, so it should not teach the convention using an
artifact from the one use case that happens to be here.
