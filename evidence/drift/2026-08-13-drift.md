## Why this matters

These files are the contract every agent reads before acting.
An instruction that no longer matches the repository does not
fail loudly -- it quietly misleads the next agent, and the
resulting mistake looks like an agent error rather than a
documentation error.

## What is being asked of you

This PR reports drift; it does not guess at the wording. Decide
whether each finding means the docs should be corrected or the
repository should be. Both are legitimate outcomes.

The detector also had no guard against reporting drift it had already reported.
Because merging a drift report is itself a push to `main`, it re-detected the
same unfixed findings and opened PR #26 — a report about the merge of a report.
That would have continued indefinitely, one PR per merge.

Both bugs share a shape worth naming: **a detector that cries wolf gets ignored
exactly when it is right.** Twelve false positives buried four true ones, and an
infinite loop would have trained the reviewer to close these unread.
